# Nuthdanai Wangpratham — personal page

Static export of the personal page shown at
<https://www.quant-corner.com/NuthdanaiWangpratham> (embedded from GitHub Pages).

The source of truth is the `quantcorner-web` app (`/NuthdanaiWangpratham` route).
This repository holds a synced copy so GitHub Pages can build it.

```bash
npm run sync   # copy the page from ../quantcorner-web
npm run build  # static export to out/
```

Pushing to `main` deploys through `.github/workflows/pages.yml`.
